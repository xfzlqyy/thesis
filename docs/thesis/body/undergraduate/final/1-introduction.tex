\section{绪论}

高保真新视角合成在虚拟现实、机器人仿真、数字孪生和自动驾驶数据生成等场景中具有重要价值。本文关注其中一个更具体且更具工程意义的设定：从移动采集得到的鱼眼图像、LiDAR 点云与 IMU 轨迹中恢复可实时渲染的室内三维高斯场景表示，以支持后续自由视点渲染与高保真场景重建。相比普通透视相机，鱼眼相机能够以更少的拍摄帧覆盖更大的室内空间，但也会显著加剧相机标定和高斯建模的难度。

在现有新视角合成方法中，传统基于点云或网格的重建方法具有明确的几何结构，但离散表示难以直接获得高保真的渲染结果；NeRF 及其变体通过连续辐射场显著提升了重建质量，却依赖密集射线采样，训练和渲染开销较高 \cite{mildenhall2021nerf,muller2022instant,fridovich2022plenoxels}。3D Gaussian Splatting（3DGS） \cite{kerbl2023} 以显式三维高斯和可微光栅化兼顾了质量与效率，已经成为高保真实时渲染的重要路线。然而，原始 3DGS 主要面向透视相机和 SfM 稀疏点云初始化设计，尚不能直接适应本文关注的鱼眼室内移动采集场景。

将 3DGS 直接应用于基于鱼眼完整室内场景重建目前面临两个重要的挑战。首先，室内场景的重建一般会进行较长轨迹的视频采集，而长轨迹鱼眼视频的 SfM 标定同时受到图片数量多与内外参耦合优化的影响，传统增量式注册与光束平差流程效率较低，会随着数据采集的轨迹增长快速上升。其次，原始 3DGS 依赖 EWA splatting \cite{zwicker2002ewa} 在透视投影下的局部线性投影近似，而鱼眼和超广角成像在边缘区域具有更强的非线性畸变，这会使真实投影明显偏离二维椭圆高斯。

已有工作开始尝试让 3DGS 适配大畸变相机。3DGUT \cite{wu20253dgut} 通过关键点采样和二维椭圆拟合来近似鱼眼投影，提升了对通用相机模型的兼容性，但当视场角进一步增大时，二维椭圆对真实投影形状的拟合误差仍然明显。3DGEER \cite{huang20253dgeer} 则直接在射线空间中对高斯进行射线积分渲染，从原理上避免了投影近似误差，但逐射线渲染会带来更高的训练与渲染成本。这些方法主要聚焦于鱼眼渲染本身，尚未同时解决鱼眼序列标定效率的问题，同时在大畸变鱼眼下的近似会引入难以忽视的误差，导致重建质量的下降。

为解决上述问题，本文提出一套基于鱼眼相机与 LiDAR 几何先验的室内 3DGS 重建管线。该管线首先利用 FAST-LIO2 \cite{xu2022fastlio2} 估计的 LiDAR-IMU 轨迹以及 LiDAR-相机预标定外参 \cite{yuan2021pixel} 为鱼眼 SfM 提供连续位姿先验，并结合 ChArUco 内参标定结果加速相机内外参优化；随后，本文自动估计鱼眼有效水平与竖直视场角，将每张鱼眼图像拆分为八张共享光心的虚拟透视图，使训练过程能够继续复用标准透视相机 3DGS 的高效渲染与优化管线；最后，本文利用 LiDAR 点云进行基于 K-d tree 的下采样与尺度感知初始化，根据局部点云协方差为高斯提供表面感知的初始化。

围绕该管线，本文在 ScanNet++ 和 Zip-NeRF 等公开鱼眼数据集上进行主要量化实验，评估鱼眼虚拟透视图训练对新视角合成质量的影响，并在 ScanNet++ 上通过消融实验分析 LiDAR 自适应初始化的作用；同时，本文在真实采集场景上对比传统增量式 SfM 与本文快速 SfM 管线，以验证几何先验辅助标定在长序列鱼眼数据中的效率收益和下游重建效果。实验设置覆盖公开鱼眼场景和真实室内采集场景，以验证该方法在鱼眼成像条件下的适用性与工程可行性。

总而言之，本文的主要贡献可概括为以下三点：

\begin{enumerate}
    \item 提出了一种基于 LiDAR-IMU 位姿先验的快速 SfM 管线，将跨传感器几何信息引入鱼眼相机内外参优化，在提高长轨迹鱼眼序列标定效率的同时，取得与传统增量式 SfM 管线相当的标定效果。
    \item 提出了一种基于虚拟透视图的鱼眼图像三维高斯重建方法，自动估计鱼眼有效水平、竖直视场角和虚拟透视图分辨率，将单张鱼眼图像拆分为八张共享光心的小视场角虚拟透视图，从而避免在强畸变投影上直接进行高斯近似。
    \item 提出了一种基于 K-d tree 的 LiDAR 点云下采样与自适应初始化方法，利用局部点云协方差初始化高斯尺度和旋转，使初始高斯能够更好适配局部表面几何并提升重建质量。
\end{enumerate}
